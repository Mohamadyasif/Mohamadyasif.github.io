# SAP Technical Portfolio — Yasif

A responsive, static HTML/CSS/JavaScript portfolio designed for free GitHub Pages hosting.

## Included
- Responsive light-theme portfolio homepage
- SAP Business ByDesign, CPI, BTP and integration skill sections
- Six project case studies with interactive detail modals
- Project category filters
- Mobile navigation
- GitHub Pages deployment instructions

## Before publishing
1. Open `index.html`.
2. Replace `your.email@example.com` with your preferred public email address.
3. Replace `https://www.linkedin.com/` with your actual LinkedIn profile URL.
4. Review the experience / project-count figures and adjust them to match your current CV.
5. Review every project summary to ensure it accurately reflects your personal contribution.
6. Do not add customer names, credentials, real payloads, production screenshots or confidential information without permission.

## Preview locally
Open `index.html` in a browser. No build tools or dependencies are required. An internet connection is only needed for the Google Fonts import; the site still works without it.

## Publish with GitHub Pages (free)
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload the contents of this folder to the repository root (make sure `index.html` is at the root, not inside another folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/ (root)`, then click **Save**.
7. Wait for the deployment to finish. Your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/`

GitHub's official guide: https://docs.github.com/en/pages/quickstart

## Updating the site
Edit `index.html`, `style.css` or `script.js`, then commit and push/upload the changes to the `main` branch. GitHub Pages republishes the site automatically.
